# CodeForge AI – User Guide

## 1. Introduction
CodeForge AI is a web-based tool designed to migrate legacy PHP code into modern Python code and review migration results.

## 2. Dashboard
The Dashboard provides an overview of the CodeForge AI project and its main features.

## 3. Code Migration
Users can select PHP files and upload them through the Migration section.

### Steps
1. Open the Migration section.
2. Click **Choose PHP Files**.
3. Select one or more PHP files.
4. Review the uploaded PHP code.
5. Click **Convert to Python**.
6. Review the generated Python code when the backend migration service is available.

## 4. Security Analysis
The Security section displays demonstration findings.

**Note:** The current security scan is not connected to a real scanning engine. Its displayed findings are demo data only.

## 5. Results
The Results section displays recorded migration and equivalence-testing results from the project dataset.

Users can select a program to view its details, function comparisons, and code examples.

## 6. Important Notes
- A successful code generation does not automatically mean the PHP and Python programs are equivalent.
- Equivalence testing requires recorded test inputs and expected outputs.
- Uploaded-file migration results are not automatically included in the recorded project results.
- Security findings should be treated as demonstration data until the security module is connected.

## 7. Support
For technical issues, contact the CodeForge AI development team.
